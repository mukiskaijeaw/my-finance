# คู่มือคัดกรองภาษีเงินได้บุคคลธรรมดาไทย

คู่มือนี้ช่วยเตรียมข้อมูลและชี้รายการที่ควรตรวจ ไม่ใช่การยืนยันสิทธิหรือการยื่นแบบแทนผู้เสียภาษี กฎขึ้นกับปีภาษี ประเภทเงินได้ สถานะบุคคล และหลักฐาน ต้องตรวจแหล่งทางการของปีนั้นก่อนสรุปยอดเสมอ

**ตรวจแหล่งข้อมูลล่าสุด:** 8 พฤศจิกายน 2569 (2026)

## อธิบายให้ผู้ใช้เห็นภาพ

แยกข้อมูลภาษีเป็นสี่ชั้น อย่าเรียกรวมว่า “รายจ่ายลดหย่อน” ทั้งหมด:

1. **เงินได้พึงประเมิน** — เงินได้รวมที่เกิดในปีภาษี และต้องจัดประเภทตามประมวลรัษฎากรมาตรา 40(1)–(8)
2. **ค่าใช้จ่ายของเงินได้** — หักตามชนิดเงินได้และวิธีที่กฎหมายกำหนด ไม่ใช่รายจ่ายจากบัญชีธนาคารทุกก้อน
3. **ค่าลดหย่อน/ยกเว้น** — สิทธิส่วนบุคคลหรือรายการที่กฎหมายระบุ หลังหักค่าใช้จ่ายแล้ว โดยมีเงื่อนไขและเพดาน
4. **เครดิตภาษี/ภาษีชำระแล้ว** — เช่น ภาษีหัก ณ ที่จ่าย ซึ่งนำไปหักจากภาษีที่คำนวณได้ ไม่ใช่ค่าลดหย่อนจากเงินได้

## จัดชนิดเงินได้ก่อนคิดค่าใช้จ่าย

ใช้ข้อเท็จจริงเรื่องความสัมพันธ์กับผู้จ่ายและลักษณะงาน อย่าตัดสินจากป้ายหมวดใน `database.csv` อย่างเดียว:

| มาตรา | ตัวอย่างทั่วไป |
| --- | --- |
| 40(1) | เงินเดือน โบนัส และประโยชน์จากการจ้างแรงงาน |
| 40(2) | ค่าธรรมเนียม ค่านายหน้า หรือค่ารับทำงานให้ |
| 40(3) | ค่าลิขสิทธิ์และค่าสิทธิ |
| 40(4) | ดอกเบี้ย เงินปันผล และผลประโยชน์บางประเภทจากเงินลงทุน |
| 40(5) | ค่าเช่า |
| 40(6) | วิชาชีพอิสระที่กฎหมายกำหนด |
| 40(7) | รับเหมาที่ผู้รับเหมาจัดหาสัมภาระสำคัญเอง |
| 40(8) | เงินได้จากธุรกิจ พาณิชย์ เกษตร อุตสาหกรรม ขนส่ง หรือกิจการอื่นที่ไม่เข้าข้อก่อนหน้า |

คำว่า “ฟรีแลนซ์” ไม่ชี้ขาดว่าเป็น 40(2), 40(6), 40(7) หรือ 40(8) ให้ถามลักษณะงานและสัญญาเมื่อมีผลต่อภาษี

แนวทางกรมสรรพากรที่ตรวจพบระบุว่าเงินได้ 40(1) และ 40(2) หักค่าใช้จ่ายเหมา 50% รวมกันไม่เกิน 100,000 บาท ส่วนประเภทอื่นใช้อัตราเหมา/ค่าใช้จ่ายจริงต่างกันตามประเภทเงินได้ เงื่อนไข และหลักฐาน ตัวเลขนี้มาจากหน้าคู่มือทั่วไปที่ปรับปรุงปี 2563 จึงต้องตรวจประกาศและกฎหมายที่ใช้กับปีภาษีจริงก่อนคำนวณ โดยเฉพาะรายการที่ต้องการใช้ค่าใช้จ่ายจริง

## รายการที่ควรชวนตรวจเรื่องสิทธิ

ใช้รายการเหล่านี้เป็นคำถามคัดกรอง ไม่ใช่การสรุปว่าใช้สิทธิได้:

- **สิทธิส่วนตัวและครอบครัว:** สถานภาพคู่สมรส บุตร บิดามารดา ผู้พิการ/ทุพพลภาพ และค่าใช้จ่ายฝากครรภ์หรือคลอดบุตร เงื่อนไขของแต่ละสิทธิและการใช้สิทธิซ้ำกับคู่สมรสต้องตรวจ
- **ประกันสังคม:** ตรวจยอดสมทบที่จ่ายจริงในปีภาษีและเพดานตามกฎหมายของปีนั้น ใช้ข้อมูล/ใบรับรองจากแหล่งที่ตรวจสอบได้ อย่านำยอดประมาณ เช่น จำนวนรายเดือนคูณ 12 มาใช้แทนยอดจริงโดยไม่ตรวจ
- **ประกัน:** ตรวจชนิดกรมธรรม์ ผู้เอาประกัน ผู้จ่าย ระยะเวลาคุ้มครอง เงื่อนไข และเพดานรวมตามปีภาษี ใบเสร็จประกันทุกชนิดไม่ได้มีสิทธิเหมือนกัน
- **การออมและกองทุนเพื่อเกษียณ:** ตรวจว่าเป็นผลิตภัณฑ์ที่กฎหมายให้สิทธิในปีนั้นจริงหรือไม่ รวมวงเงินกับสิทธิกลุ่มเดียวกัน และเงื่อนไขการถือ/ขาย กองทุนรวมหุ้นหรือกองทุนทั่วไปไม่ได้ลดหย่อนเพียงเพราะเป็นการลงทุน
- **ดอกเบี้ยกู้ซื้อ/สร้างที่อยู่อาศัย:** พิจารณาเฉพาะดอกเบี้ยที่เข้าเงื่อนไข ไม่ใช่เงินต้นหรือยอดผ่อนบ้านทั้งหมด ต้องมีหนังสือรับรองจากผู้ให้กู้
- **เงินบริจาค:** ต้องตรวจชนิดหน่วยรับบริจาค วัตถุประสงค์ วิธีจ่าย อัตรา/เพดาน และข้อมูลหลักฐาน กรมสรรพากรแจ้งว่าเงินบริจาคที่ประสงค์ใช้สิทธิในกลุ่มหน่วยรับบริจาคที่ประกาศ ต้องผ่าน e-Donation ตั้งแต่ 1 มกราคม 2569; อย่าสรุปสิทธิจากสลิปโอนเงินอย่างเดียว
- **มาตรการชั่วคราว:** เช่น มาตรการซื้อสินค้า/ท่องเที่ยว/ซ่อมแซม จะพิจารณาได้เมื่อมีประกาศที่ครอบคลุมปีนั้น วันที่ ประเภทผู้ขาย/บริการ และใบกำกับหรือหลักฐานตามที่กำหนดเท่านั้น
- **ค่าใช้จ่ายที่เกี่ยวกับกิจการ:** อาจเป็นค่าใช้จ่ายของเงินได้บางประเภท หากจำเป็นและสัมพันธ์กับการหารายได้ เข้าเงื่อนไขของประเภทเงินได้ และมีหลักฐานเพียงพอ อย่าปนกับค่าลดหย่อนส่วนบุคคล และอย่าหักเพิ่มซ้ำกับวิธีเหมา

## รายจ่ายที่ไม่ใช่ค่าลดหย่อนโดยอัตโนมัติ

อาหาร ของใช้ เสื้อผ้า เดินทางส่วนตัว โทรศัพท์/อินเทอร์เน็ต ความงาม โรงแรมทั่วไป และ subscription เช่น AI หรือ cloud **ไม่เป็นค่าลดหย่อนเพียงเพราะมีใบเสร็จหรือบันทึกในบัญชี** รายการอาจเปลี่ยนเป็นกรณีเกี่ยวกับกิจการหรือเข้าโครงการเฉพาะได้ แต่ต้องมีฐานกฎหมาย ประเภทรายได้ วันที่ และหลักฐานรองรับก่อน

โดยทั่วไป การโอนระหว่างบัญชีตนเอง การคืนเงินต้นบัตรเครดิต การซื้อหุ้น/คริปโท/กองทุนทั่วไป หรือการจ่ายภาษีไม่ใช่ค่าลดหย่อนจากเงินได้โดยตัวมันเอง แต่อาจมีผลภาษีแยกต่างหากเมื่อเกิดดอกเบี้ย เงินปันผล การขาย หรือเข้าเงื่อนไขผลิตภัณฑ์เฉพาะ ให้แยกเหตุการณ์เหล่านั้นและตรวจเป็นกรณี

ใช้ถ้อยคำให้แม่น: **“รายการนี้ยังลดหย่อนไม่ได้จากข้อมูล/หลักฐานที่มี”** หรือ **“ไม่เข้าเงื่อนไขที่ตรวจพบสำหรับปีนี้”** แทนคำว่า “ลดหย่อนไม่ได้ตลอดไป” เว้นแต่ตรวจข้อกฎหมายและข้อเท็จจริงครบแล้ว

## แนวทางบันทึกในไฟล์จริง

- เริ่มจาก `AGENTS.md` และใช้ `database.csv` กับ `tax_preparation.csv` จริงของโฟลเดอร์เป็นข้อมูลหลัก คง schema, ลำดับวันที่, `transaction_id`, source reference และแถวเดิมไว้
- เพิ่มแถวภาษีเฉพาะเมื่อรายการมีเหตุผลที่น่าจะเกี่ยวข้อง เช่น เงินได้ ประกันสังคม ประกัน/กองทุน ดอกเบี้ยบ้าน เงินบริจาค หรือค่าใช้จ่ายของกิจการที่ชัดเจน ไม่ต้องสร้างรายการภาษีจากทุกใบเสร็จค่าอาหาร/ช้อปปิ้ง
- แยก `record_type`: เงินได้เป็น `income`; รายการที่อาจเป็นค่าลดหย่อนเป็น `deduction`; ภาษีหัก ณ ที่จ่าย/ภาษีที่ชำระเป็น `tax_paid` ตาม schema ของ workspace อย่ารวมรายการรายละเอียดกับ `income_total`/`deduction_total` หรือ snapshot เดิม
- ระบุ `tax_category` ให้เข้าใจได้ เช่น `มาตรา 40(1) เงินเดือน`, `เงินสมทบประกันสังคม`, `เบี้ยประกันสุขภาพ`, `ดอกเบี้ยกู้ซื้อที่อยู่อาศัย`, `เงินบริจาคผ่าน e-Donation` และบันทึก `source_reference`, `document_status`, `review_status`, `notes` ตามข้อเท็จจริง
- คงแถวเงินเดือนใน `database.csv` เป็นยอดเงินสดที่รับจริง หากเป็นยอดสุทธิอย่าแก้ให้เป็นยอด gross สำหรับเตรียมภาษี ให้ใช้ยอดเงินได้รวมและภาษีหัก ณ ที่จ่ายจากหนังสือรับรอง 50 ทวิ/เอกสารนายจ้าง แล้ว reconcile กับยอดรับสุทธิแทน หาก salary ถูกหักประกันสังคมแล้ว อย่าหักเงินสมทบออกจาก gross income ซ้ำ และอย่าบันทึกค่าลดหย่อนก้อนเดียวกันซ้ำ
- รายการลดหย่อนผู้สมัครต้องเป็น `needs_review` จนตรวจปีภาษี เงื่อนไข ยอดจริง และเอกสารแล้ว หากไม่ทราบอย่าแต่งจำนวน ให้เว้นยอดหรือบันทึกข้อสงสัยใน `notes` ตาม schema
- My Tax Account ใช้ตรวจทานได้ แต่กรมสรรพากรระบุว่าข้อมูลเงินได้/ภาษีหัก ณ ที่จ่ายที่แสดงมาจากข้อมูลซึ่งผู้จ่ายส่งทางอิเล็กทรอนิกส์ และหากข้อมูลไม่ครบ/ไม่ถูกต้องผู้เสียภาษีแก้ในแบบได้ จึงต้อง reconcile กับเอกสารผู้จ่ายและหลักฐานของผู้ใช้ ห้ามขอรหัสผ่านหรือรับช่วงล็อกอินแทน
- เมื่อแนะนำครั้งแรก ให้เสนอให้สำรวจปีภาษี แหล่งเงินได้และประเภท 40(1)–(8) สถานะครอบครัว และหลักฐานของสิทธิที่อาจมี ถามเฉพาะข้อมูลที่จำเป็นต่อการคัดกรองครั้งนั้น ไม่ขอข้อมูลอ่อนไหวเกินงาน

## แบบและกำหนดยื่น

แนวทาง RD แยก ภ.ง.ด.91 สำหรับผู้มีเฉพาะเงินได้ 40(1), ภ.ง.ด.90 สำหรับเงินได้ประเภทอื่นร่วมด้วย, และ ภ.ง.ด.94 ครึ่งปีสำหรับเงินได้ 40(5)–(8) ที่เข้าเงื่อนไข โดยทั่วไป ภ.ง.ด.90/91 ยื่นช่วงมกราคม–มีนาคมปีถัดไป และ ภ.ง.ด.94 ยื่นช่วงกรกฎาคม–กันยายนของปีภาษีนั้น ตรวจวันครบกำหนดจริงและการขยายเวลายื่นออนไลน์ของแต่ละปีอีกครั้ง

ณ วันที่ตรวจ คู่มือค่าลดหย่อนที่พบในเว็บไซต์ RD เป็นของปีภาษี 2568 ส่วนหน้าแบบภาษีปี 2569 มีข้อมูลแบบ ภ.ง.ด.93/94 แต่ยังไม่ใช่ตารางสิทธิประจำปีครบถ้วน ห้ามนำมาตรการเฉพาะกิจหรือเพดานของปี 2568 มาใส่ปี 2569 โดยอัตโนมัติ
