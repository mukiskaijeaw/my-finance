# ผู้ใช้ใหม่ต้องให้อะไรบ้าง

เอกสารนี้เป็นแนวทางถามผ่านข้อความในแชท ไม่ใช่ฟอร์มที่ต้องส่งให้ผู้ใช้กรอก ผู้ใช้เริ่มได้ด้วยการพิมพ์หรือแนบรูปในช่องแชทหลัก ไม่ส่ง onboarding UI หรือรูปที่ผู้ใช้แนบกลับไปซ้ำ ใช้การ์ดและรูปเฉพาะตอนตอบเสนอสินค้า/ผลประเมิน

## ค้นสินค้า / เทียบราคา

จำเป็นเพียงชื่อ รูป ลิงก์ หรือคำอธิบายสินค้าสักอย่าง งบ สี ไซส์ รสชาติ การใช้งาน วันต้องการรับ และช่องทางที่ชอบเป็นข้อมูลเสริม ถ้าข้อมูลพอให้ค้นทันที ไม่ขอรายได้หรือฐานข้อมูลการเงิน

Agent หาเอง: รูปจริงพร้อม source รุ่น/variant ร้าน ราคา ค่าส่ง ส่วนลดและสิทธิ์ สต็อก และวันที่ตรวจ ไม่ขอให้ผู้ใช้เขียน JSON

## ซื้อไหวไหม / ซื้อเมื่อไร / กระทบเงินไหม

เริ่มด้วยแหล่งข้อมูลที่ผู้ใช้เลือกเชื่อม ไม่ต้องส่งข้อมูลทั้งหมดผ่านแชท `thai-finance-agent` เป็นตัวอย่าง provider ภายในเครื่อง ไม่ใช่ dependency บังคับและไม่ใช่ที่เก็บ code ของ Pillar 4

| ข้อมูล | ความหมายและเหตุผล |
|---|---|
| แหล่ง Pillar 1 | พาธ workspace local ที่ต้องการใช้ หรือให้ข้อมูลสรุปเอง ถ้ายังไม่เชื่อมไม่อ่าน source ใด |
| รายได้สุทธิต่อเดือน | เงินรับจริง รายได้คงที่หรือไม่แน่นอน; variable ต้องมีอย่างน้อย 3 เดือนที่ครบ |
| รายจ่ายจำเป็น | ค่าอยู่กิน เดินทาง บ้าน ฯลฯ แยกจากหนี้และเป้าหมายออม |
| ยอดชำระหนี้ต่อเดือน | ยอดที่ต้องจ่าย ไม่ใช่ยอดหนี้ทั้งหมด |
| เป้าหมายออม/ลงทุน | ส่วนที่ต้องรักษาไว้แต่ละเดือน |
| เงินสดทั้งหมดปัจจุบัน | ใช้ประเมินซื้อได้ตอนนี้ ไม่ใช่ monthly surplus หรือ budget สินค้า |
| เงินฉุกเฉินที่ห้ามแตะ | ส่วนหนึ่งของเงินสดทั้งหมด ไม่บวกเงินเพิ่ม |
| เงินกันบิลที่ยังค้าง | ไม่หักบิลที่จ่ายแล้วซ้ำ |
| ภาระเพิ่มในอนาคต | จำนวนและเดือนที่ครบกำหนด ไม่ซ้ำกับงบประจำ/เงินกันบิล |
| เงินกันซื้อเฉพาะสินค้า | ถ้ามี เป็นส่วนหนึ่งของเงินสด ไม่จำเป็นต้องมี |
| วันที่/ความครบถ้วน | ข้อมูลเป็นปัจจุบันไหม มีภาระตกหล่นหรือนับซ้ำไหม |

อ่าน schema จริงของ provider ก่อนเสมอ Adapter ตัวอย่างรองรับ transaction CSV 14 คอลัมน์ของ Thai Finance Agent ยอดธุรกรรมไม่ยืนยันยอดเงินสด หนี้ หรือความครบของเดือน จึงถามเพิ่มเฉพาะช่องที่ provider/ผู้ใช้ยังไม่ยืนยัน

ตัวอย่างเชื่อมเฉพาะคำขอนั้น (รันจาก shopping-agent):

```text
python .agents/skills/shopping-agent/scripts/shopping.py ledger --finance-dir ../thai-finance-agent
python .agents/skills/shopping-agent/scripts/shopping.py evaluate --finance-dir ../thai-finance-agent --format markdown
```

คำสั่ง evaluate รับ JSON จาก agent ผ่าน stdin การค้นราคา/รูป/query ไม่อ่าน provider แม้กำหนด FINANCE_DIR ไว้ ไม่บันทึกสำเนา CSV/profile ไว้ใน Pillar 4

อย่าขอเลขบัญชี เลขบัตร รหัสผ่าน หรืออัปโหลดสลิป/CSV ออกไป services ภายนอก Mock เป็น opt-in demo แยกข้อมูลจริงเท่านั้น
